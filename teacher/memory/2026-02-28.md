## Concetti nuovi/rafforzati
- Carry flag come "riporto" nella somma in colonna
- ADC fa sempre A + valore + Carry
- Somme a 16 bit: CLC, somma bassi, poi alti senza CLC (il carry si propaga)
- ASL moltiplica per 2, bit 7 esce nel Carry
- ROL raccoglie il Carry nel bit 0 (per moltiplicazioni 16-bit)
- Decomposizione moltiplicazione: 40 = 32 + 8, quindi N*40 = N*32 + N*8
- `adc #0` per propagare solo il carry al byte alto
